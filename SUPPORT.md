# Support

- **Usage questions and design discussion:** [GitHub Discussions](https://github.com/RhinoLink-Tech/data-fabric/discussions).
- **Reproducible bugs:** search existing issues, then choose the Bug report form.
- **Feature requests:** choose the Feature request form.
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md); do not post them publicly.

Before asking for help, check the [README](README.md), [configuration guide](docs/configuration.md), and [API guide](docs/api_usage.md). Include the version or commit, Go version, operating system, relevant configuration with secrets removed, and steps to reproduce.

This community-maintained project does not currently promise response or support times.
